# course_project

Objective:- The objective of this task is to implement a parallel vector product
using MPI functions, specifically MPI Reduce and MPI Bcast or MPI
Allreduce.

Task-2:-
Objective:- Implementation of the Gram-Schmidt orthogonalization algorithm
in a parallelized manner using MPI.

Task-3, Task-4, Task-5 & Task-7:-
Objective:- Parallel matrix stencil, Jacobi iteration, steepest descent, and
performing there weak and strong scaling
